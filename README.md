# constructive-extension · 构造数学·延伸篇（科普系列）

构造数学科普系列的**延伸篇**：同一套笔法（问句切入/比喻承载/主流与体系分栏/每篇四个可验资产），从数学层进入物理世界。

| 篇 | 标题 | 问题 |
|---|---|---|
| 01 | 能量住在哪 | "能量是什么"是循环→换问"住在哪" |
| 02 | 能量隔着什么 | 能量怎么被摸到（隔离能） |
| 03 | 东西为什么有大小 | 为什么存在"典型尺寸"（锚塔+房租） |
| 04 | 确认是什么 | "确认"这个动作的最小结构（配对结构） |
| 05 | 参考架从哪来 | 参考架=观察点网络的显化（四点盖房） |

主线一句话：**没有一样"静的东西"是白给的。**
